# 그림자 도시 5.0 — 모바일 웹 배포판

실제 언어 모델을 호출하는 서버형 마피아 게임입니다. 휴대폰 Chrome/Safari에서 별도 설치 없이 플레이할 수 있습니다. **공개 URL은 배포를 마쳐야 생성됩니다.**

## Render로 배포하기

1. 이 폴더의 파일을 GitHub 저장소 루트에 업로드합니다 (`server.js`, `engine.js`, `package.json`, `render.yaml`, `public/index.html`).
2. [Render](https://dashboard.render.com/)에서 **New → Blueprint**를 선택하고 GitHub 저장소를 연결합니다.
3. `OPENAI_API_KEY`에 본인의 OpenAI API 키를 Render의 **Environment** 설정에서 입력합니다. **GitHub나 HTML 파일에 키를 올리지 마세요.**
4. 배포가 완료되면 Render가 제공하는 `https://...onrender.com` 주소를 모바일 브라우저에서 엽니다.
5. Render의 무료 플랜 사용 가능 여부 및 휴면/요금 정책은 계정과 시점에 따라 달라질 수 있습니다. OpenAI API 요금은 별도입니다.

## 로컬 실행

Node.js 20 이상에서 `OPENAI_API_KEY` 환경 변수를 설정한 뒤 `npm start`, 브라우저에서 `http://localhost:3000`.

## 배포판 개선

- 접속 기기마다 별도의 게임 세션 (HttpOnly 쿠키) — 다른 사용자의 게임이 덮어써지지 않습니다.
- API 키는 서버 환경 변수에만 저장합니다.
- AI 요청에 세션당 분당 5회, 서버 전체 분당 40회 제한; 중복 AI 호출 방지.
- 모바일 스크롤/이전 대화 버튼 및 답장 기능 유지.
- `/health` 상태 확인 경로, `PORT` 및 `0.0.0.0` 호스팅 지원.

## 중요한 한계

- 서버 재시작/휴면 시 메모리에 저장된 게임이 사라집니다. 세션은 약 6시간 동안 유지됩니다.
- 자동 AI 토론은 API 호출을 계속 발생시켜 요금이 늘어날 수 있으므로 필요 없을 때 끄세요.
- 별도 계정 인증, 데이터베이스, 관리자용 사용량 통계, 결제 상한은 아직 없습니다. 공개 대규모 서비스 전에는 보완이 필요합니다.
- AI는 실제 모델이 대사를 만들지만 게임의 밤 행동/투표 전략은 여전히 규칙 기반입니다.
- 모든 능력 상호작용과 장시간 플레이가 완전히 검증된 것은 아닙니다.
